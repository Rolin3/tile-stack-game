About Tile Stack

A small, focused puzzle game built by one person who believes games should respect your time and intelligence.

Our Mission

Tile Stack exists for one reason: to prove that a free browser game can be genuinely fun without manipulating you into watching ads, creating accounts, or waiting for energy refills.

The mobile gaming industry has trained players to accept questionable design patterns as normal. Forced ad breaks. Artificial energy systems that limit playtime. Dark pattern UI that makes canceling subscriptions difficult. Notification spam. Social pressure mechanics. Tile Stack rejects all of this.

Our Design Principles

  1. Instant Play: Open the site, tap PLAY, start matching. No downloads, no account creation, no tutorial walls.
  2. Skill Over Luck: Every level is mathematically verified solvable. You lose because of your decisions, not because the game dealt you an unwinnable hand.
  3. Respect Your Time: No forced ad interruptions during gameplay. No energy systems. No "wait 30 minutes or pay" mechanics. Play as much as you want, whenever you want.
  4. Transparency: Clear privacy policy. No hidden data collection. No tracking beyond what is necessary for ads and basic analytics.
  5. Polish: Smooth animations, responsive design, thoughtful color choices, and satisfying feedback on every interaction. Free does not mean cheap.

The Story Behind Tile Stack

Tile Stack started as a weekend experiment in June 2026. The creator, an independent developer and product manager, was playing a popular tile-matching mobile game during a commute and kept running into the same frustrations: a 30-second unskippable ad after every level, an energy system that stopped play after 15 minutes, and constant prompts to subscribe or connect social accounts.

The thought was simple: "I could build a cleaner version of this. No nonsense. Just the game."

What began as a weekend project quickly grew into something more. The core gameplay came together in the first two days — tile stacking logic, slot management, match detection, win/loss conditions. But then came the details that separate a prototype from a polished experience: smooth animations, touch handling that feels native on mobile, undo and shuffle tools that feel fair rather than pay-to-win, a daily challenge system that gives players a reason to return, and a leaderboard that creates friendly competition without toxic social pressure.

How It's Built

Tile Stack is intentionally built with minimal dependencies. Every line of code is hand-written, every animation is custom-crafted, and every design decision is deliberate. Here is what powers the game:

Frontend

Pure HTML5 + CSS3 + Vanilla JavaScript. No frameworks, no bundlers, no build steps. Loads instantly, works everywhere.

Backend API

Cloudflare Workers provides the server logic for daily challenges, leaderboards, and ad verification. Edge-deployed for global low latency.

Data Storage

Cloudflare KV (Key-Value) store holds leaderboard scores, daily challenge seeds, and verification tokens. Simple, fast, cost-effective.

Hosting

GitHub Pages serves the main site (rolin3.github.io). Cloudflare Pages handles the standalone game deployment. Both free tiers.

Analytics & Ads

Google AdSense for non-intrusive advertising that supports ongoing development. Privacy-first approach with clear disclosure.

Version Control

Git with two repositories: one for the game engine, one for the website. Open source code available on GitHub.

Why This Stack?

Every technology choice traces back to the core principles:

  • No framework = instant loading, zero overhead, maximum compatibility across all browsers and devices.
  • Cloudflare Workers = serverless scalability without managing servers, pay-per-use pricing suitable for an indie project.
  • GitHub Pages = free, reliable hosting with automatic SSL, perfect for static content sites.
  • KV storage = the right tool for simple key-value data. No need for a full database for leaderboards and daily seeds.

What's Next

Tile Stack is actively developed. Here is what is on the roadmap:

  • New Tile Themes: Beyond emoji tiles — classic Mahjong-style, geometric patterns, seasonal themes, and possibly community-submitted designs.
  • Audio Upgrade: More polished sound effects for matches, shuffles, wins, and losses. Multiple BGM options or ambient sound modes.
  • New Power-ups: Additional tools for tricky situations — perhaps a "hint" that highlights a safe move, or a "freeze" that temporarily prevents slot overflow.
  • Social Challenges: Challenge friends to beat your score on a specific level. Generate shareable links that open directly to that level.
  • Campaign Mode: A curated set of hand-crafted levels with increasing difficulty, telling a visual story as you progress through worlds or themes.
  • Accessibility Improvements: Better keyboard navigation, screen reader support, high-contrast mode, and reduced-motion options.
  • Performance Mode: Optimizations for very low-end devices, ensuring playable frame rates even on older smartphones.

The priority order is driven by player feedback. If there is something you want to see, reach out through the contact information below.
